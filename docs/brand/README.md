# Torii — logo i identyfikacja

Materiał dostarczony przez właściciela produktu 2026-09-19.
**Oryginalny JPG jest już używany w README oraz w lokalnym demo i fundamencie
interfejsu enterprise.** Warianty wektorowe i pełny system identyfikacji
pozostają do przygotowania i przeglądu.

## Pochodzenie i używane pliki

[Oryginał referencyjny](assets/torii-logo-reference.jpg) jest kopią pliku

`ced80ee91284360fbe0fc98507d03093edb802107f6dc0039c41f936603c6b95`

Motyw: brama torii z liniami przypominającymi połączenia elektroniczne,
czerwono-koralowy i błękitny akcent, ciemne tło, jasny napis TORII.
Zmiana rozmiaru wyświetlania przez CSS nie zmienia pliku źródłowego.
Nie wygenerowano ani nie zadeklarowano zatwierdzenia nowych wariantów logo.

## Co pozostaje do przygotowania — SPEC-0017

- Zasady użycia znaku i napisu, pole ochronne i minimalne rozmiary.
- Wariant nawigacyjny, favicon oraz wersje na jasne i ciemne tło;
  preferowany docelowy asset wektorowy. Dostarczony JPG nie ma przezroczystości.
- Uzgodnione tokeny kolorystyczne, typografia, focus, gęstość tabel i czytelność
  małych etykiet wraz z weryfikacją dostępności. Obecne style demo nie są
  zatwierdzonym kompletnym systemem identyfikacji produktu.
- Potwierdzenie praw do publikacji przed zewnętrzną dystrybucją.
  Nazwa pliku ani jego użycie lokalne nie są dowodem licencji lub rejestracji znaku.

Na ekranach roboczych logo nie powinno zastępować czytelnej powierzchni dla
tabel, formularzy i przepływów. Kolory marki oddzielamy od statusów, alarmów
i oznaczeń środowiska. „DEMO”, „DEV” lub przyszła „PRODUKCJA” wymagają jawnej
etykiety — czerwony akcent logo nie oznacza błędu.
