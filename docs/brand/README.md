## Przygotowanie do interfejsu — zakres SPEC-0017

- Ustalić użycie znaku, napisu, pole ochronne i minimalne rozmiary.
- Przygotować do przeglądu wariant nawigacyjny, favicon oraz jasne/ciemne tło;
  preferowany docelowy asset wektorowy. Dostarczony JPG nie ma przezroczystości.
- Nie wstawiać całego dużego obrazu jako tła każdego ekranu roboczego.
  Tabele, formularze i Flow potrzebują spokojnej, czytelnej powierzchni.
- Oddzielić kolory marki od znaczenia statusów, alarmów i środowisk.
  Produkcja musi mieć również tekst/ikonę; czerwony akcent logo nie oznacza błędu.
- Uzgodnić tokeny, typografię, focus, gęstość tabel i czytelność małych etykiet;
  zweryfikować dostępność przed przyjęciem wariantu do produktu.
- Zapisać pochodzenie i uzyskać potwierdzenie praw do publikacji przed zewnętrzną
  dystrybucją. Nazwa pliku nie jest dowodem licencji ani zarejestrowanego znaku.

Materiały robocze identyfikacji pozostają poza runtime aplikacji, dopóki nie
zostaną przygotowane i zatwierdzone. Nie wygenerowano nowych wariantów logo.
