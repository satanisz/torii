## Suggested workflow

1. Put immutable source data in `data/raw`.
2. Explore ideas in `notebooks`, but move reusable logic into `src`.
3. Save intermediate data in `data/interim` and final datasets in
   `data/processed`.
4. Store trained artifacts in `models` and generated outputs in `reports`.
5. Add automated checks in `tests`.

The image environment is already active. `uv` is available for project-level
package changes, for example `uv add <package>` or `uv pip uninstall <package>`.
